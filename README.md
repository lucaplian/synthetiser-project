# Synthesizer Project - DP-CTGAN & Differential Privacy Research

## Setup & Environment
Run these files in kaggle, in order to have the proper file environment, and to have the neccesary computation power to run the models, as the neural network based synthetizers are very demanding.

### Datasets:
* **Numberbatch Dataset:** The numberbatch dataset can be downloaded from: https://www.kaggle.com/datasets/lucaplian/numberbatch-en. 
* **Census Dataset:** Download the "adult-data-census.csv" file and upload it in the kaggle datasets, in order to have the dataset privately, or you can directly used the following link: https://www.kaggle.com/datasets/lucaplian/adult-data-census.
